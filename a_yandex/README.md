Суммирует массивы целых чисел, переданные во 2-й и 4-й строках файла input.txt так, что в результирующем массиве: s(i) = a(i) + b(i).
Если в каком-то массиве чисел меньше, то добавляются нулевые элементы с начала массива, а потом проводится суммирование.

input.txt:

-- String 1
100 222 1234 777
-- String 2
333 4321 223

-- Some other text
-- FINAL --

output.txt:

3
100 555 5555 1000
